# 🌐 DreamVenture Website

Welcome to the official website of **DreamVenture Personnel Solutions**, built to showcase our services, location, and contact information with an elegant and modern interface.

## 🚀 Live Demo

🌍 [Visit the Website](https://darkshadow0001boss.github.io/dreamventures/)  
---

## 🧩 Features

- ✨ Smooth animations with AOS
- 🌌 Dynamic 3D background using Vanta.js
- 🗺️ Interactive Mapbox integration for office location
- 📱 Fully responsive across all devices
- 🎨 Clean UI with Bootstrap 5
- 🔗 Social media links
- 📞 Contact section with location, email, and call info

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3 + SCSS**
- **JavaScript**
- **Bootstrap 5**
- **Vanta.js**
- **Spline 3D**
- **Mapbox GL JS**
- **Google Maps Embed**
- **AOS (Animate on Scroll)**
